# App fonts

The Android app bundles the official Google Fonts variable TTFs and the accompanying SIL Open Font License texts.

- **Sora**: headings at weight 600; statistics at weight 500. Source: https://raw.githubusercontent.com/google/fonts/main/ofl/sora/Sora%5Bwght%5D.ttf. License: https://raw.githubusercontent.com/google/fonts/main/ofl/sora/OFL.txt.
- **Manrope**: body and note text at weight 400; buttons/navigation at weight 600; the lowercase `logbook` wordmark at weight 700. Source: https://raw.githubusercontent.com/google/fonts/main/ofl/manrope/Manrope%5Bwght%5D.ttf. License: https://raw.githubusercontent.com/google/fonts/main/ofl/manrope/OFL.txt.

The bundled logo at `app/src/main/res/drawable-nodpi/logbook_logo.png` is the user-supplied image copied without modification.
